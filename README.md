# Vibe Scripts

Userscripts for Tampermonkey or Violentmonkey. Click a link to install.

- [Video Keys](https://github.com/joshuali925/vibe-scripts/raw/main/video-keys.user.js): keyboard shortcuts for HTML5 video, covering speed, seeking, frame stepping and maximize-in-window.
- [HN Modern](https://github.com/joshuali925/vibe-scripts/raw/main/hn-modern.user.js): a readable, modern restyle of Hacker News with light and dark themes and Reddit-style comment threads.
